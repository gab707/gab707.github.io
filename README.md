# Gab707 — GitHub Pages

Static production site for https://gab707.github.io. No build step, database, or server code is needed.

## Publish

1. Open the `gab707/gab707.github.io` repository on GitHub.
2. Upload the contents of this package at the repository root, including `.nojekyll`.
3. Commit the files.
4. In Settings → Pages, select **Deploy from a branch**, then **main** and **/(root)**.
5. Open https://gab707.github.io after GitHub finishes deploying.

`index.html` is the home page and `about/index.html` is the About page. The contact form sends through Formspree endpoint `moedpvwe`; delivery goes to the address configured in that Formspree account.
